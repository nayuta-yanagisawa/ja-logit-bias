# Strata の DeepSeek エンジンに logit_bias を通すパッチ

[Strata](https://github.com/Niko1221/Strata) の v0.2.7 では、Qwen のエンジンは `logit_bias` を受け付けますが、DeepSeek-V4.1 のエンジンは受け付けません。サンプラーには禁止リストを足し込む処理がありますが、リクエストの値をそこまで渡す配線がなく、エンジンも対応を申告しないので、サーバーが拒否します。

`deepseek-v4.1-logit-bias-v0.2.7.patch` は、その配線を足します。

- リクエストの `logit_bias=ID:値,...` を、Qwen のエンジンと同じ共通の部品（`strata::core::parse_logit_bias`）で読み、GPU に置きます。-100 は確実な禁止（負の無限大）になります。
- 通常の生成、下書きの検証、検証での引き直しの、すべてのサンプリングに渡します。
- エンジンが `INFO logit_bias=1` を出し、サーバーがリクエストを通すようにします。
- 不正な値は `ERR logit_bias: ...` で拒否します。そのとき、前のリクエストの禁止リストは外します。

v0.2.7 のタグに `git apply` で当たります。v0.2.10 では DeepSeek のエンジンのコードが変わっていて、当たりません。

確かめたこと（DeepSeek-V4.1-Flash IQ2_XXS、RTX 3090（24 GB）1 枚、2026-11-05）：

- 「東京」を書くトークンを禁止すると、「日本の首都は？」に東京と答えなくなり、禁止を外したリクエストでは東京と答える
- 語彙の外の ID を送ると、サーバーが 400 を返す
- このリポジトリの評価（`eval/`）を、DeepSeek でもこのパッチで流した
